# ASA-RV3D Paper Artifacts

This directory contains the manuscript-facing result snapshot for:

> Constrained Post-Partition Refinement for RISC-V 3-D Tier Partitioning

The files here are intended to provide a compact mapping between the values reported in the paper and the public repository. They are a paper-reported snapshot, not a claim that every historical generated CSV under `results/` automatically regenerates the same values.

Files:

- `artifact_manifest.md`: provenance and interpretation notes.
- `table2_partition_results.csv`: partition-level Context-OFF / Context-ON result snapshot.
- `table3_path_validation.csv`: downstream path-level validation snapshot.

For the paper-facing interpretation, use this directory together with the top-level `README.md`.
