# Figure Layout

This directory separates exploratory plots from cleaner current-stage summary figures.

## exploratory

Intermediate and diagnostic figures used to inspect each experiment phase.

- `partition_v1/`: first architecture-aware partition comparison.
- `partition_v2/`: score-based partition comparison.
- `partition_v2_sweep/`: parameter sweep diagnostics.

## summary

Cleaner high-level figures for current reports, discussions, and presentations. These are not final paper figures; later experiments may replace or supersede them.
